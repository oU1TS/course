# Group Technical Discussions into Sequence Dropdowns

Group technical discussions belonging to the same sequence (e.g. `#1`, `#1.1`, `#1.2` under Technical Discussion `#1`) into a intermediate dropdown menu accordion under the "Technical Discussions" root section, matching the structure used by Course Discussions.

## User Review Required

> [!IMPORTANT]
> **Data Model Enhancement**: `technical.json` will be updated from a flat `discussions` array to a `topics` array containing sequence/topic objects (`topicId`, `topicName`, `discussions`). Backward compatibility for flat `discussions` will remain supported in `app.js`.

> [!NOTE]
> The dropdown menu header will display **"Technical Discussion #1"** (containing the 3 listing items `#1.2`, `#1.1`, and `#1`), with a badge showing count `3` and a dedicated copy link button (`#discussions?topic=tech-disc-1`).
