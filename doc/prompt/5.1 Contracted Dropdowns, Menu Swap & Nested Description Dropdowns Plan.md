# Contracted Dropdowns, Menu Swap & Nested Description Dropdowns Plan

This plan details the changes needed to contract all discussion dropdown menus by default, swap the root menu section order (Course Discussions first, Technical Discussions second), and add nested session description dropdowns inside each entry card, backed by updated `course.json` and `technical.json` data.

## Proposed Changes

### 1. Data Models (`course.json`, `technical.json`, `lecture.json`)

#### [MODIFY] [course.json](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/course.json)
- Add a `"description"` string field to each lecture entry (e.g., OOP basics, recursion & DP, vector fields details).

#### [MODIFY] [technical.json](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/technical.json)
- Add a `"description"` string field to each technical discussion entry with session overview / YouTube details.

#### [MODIFY] [lecture.json](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/lecture.json)
- Mirror the added `"description"` fields to remain consistent with `course.json`.

---

### 2. Discussion Page Structure & Logic (`app.js`)

#### [MODIFY] [app.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/app.js)
- **Default Contracted State**:
  - Update root accordion headers (`.root-accordion-header`) and course accordion headers (`.course-accordion-header`) to render with `aria-expanded="false"`.
  - Set content container inline style to `style="max-height: 0;"`.
- **Reorder Root Sections**:
  - Move "Course Discussions" (`id="root-section-course"`) above "Technical Discussions" (`id="root-section-technical"`).
- **Nested Description Dropdowns**:
  - Add a collapsible description toggle button (`.card-desc-toggle`) and content block (`.card-desc-content`) inside each discussion card (`.discussion-card`).
  - If a description exists, enable expanding/contracting the nested description dropdown.
- **Event Binding**:
  - Add event listeners in `setupViewInteractions('discussions')` for `.card-desc-toggle` elements so users can click to expand/collapse descriptions smoothly.

### 3. Styling & Animations (`style.css`)

#### [MODIFY] [style.css](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/style.css)
