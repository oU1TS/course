# Walkthrough - Multiple Notes Support (`notesUrl`)

Implemented logic to support multiple note files for `notesUrl` in `course.json` and `technical.json`. When a lecture or technical discussion has multiple note attachments, a "Lecture Notes (N)" button triggers an interactive popup modal displaying the list of available notes.

## Changes

### Data & Content
#### [course.json](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/course.json)
- Refactored `cse-0611327-cgm-l1` to convert duplicate `"notesUrl"` keys into a clean JSON array of URLs:
```json
"notesUrl": [
  "https://github.com/user-attachments/files/30556635/8085-pin-diagram-memorization-technique.pdf",
  "https://github.com/user-attachments/files/30592546/03.RISC.CISC.and.8085.pins.pdf"
]
```

### User Interface
#### [index.html](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/index.html)
- Added `#notes-select-modal` overlay dialog markup matching the styling system of `#lecture-select-modal`.

#### [app.js](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/app.js)
- Added note normalization helpers (`normalizeNotesUrl`, `deriveNoteTitle`, `renderNotesButtonHtml`):
  - Single string -> Direct note link button.
  - Array of note URLs or objects (`{ title, url }`) -> Multiple notes button `Lecture Notes (N)` that triggers the popup modal.
- Implemented `openNotesSelectModal` and `closeNotesSelectModal` controller functions with backdrop click, close button, and `Escape` key handling.
