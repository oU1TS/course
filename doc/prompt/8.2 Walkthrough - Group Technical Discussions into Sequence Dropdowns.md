# Walkthrough - Group Technical Discussions into Sequence Dropdowns

Grouped technical discussions belonging to sequence `#1` (`#1`, `#1.1`, and `#1.2`) into a parent sequence accordion dropdown menu titled **"Technical Discussion #1"** under the **"Technical Discussions"** section.

## Key Changes

### Data Model & Content
#### [technical.json](file:///c:/Users/.../Documents/GitHub/%5BoU1TS%5D/course/technical.json)
- Refactored top-level schema to use a `topics` array.
- Grouped `tech-disc-1.2`, `tech-disc-1.1`, and `tech-disc-1` under a sequence topic object:
  - `topicId`: `"tech-disc-1"`
  - `topicName`: `"Technical Discussion #1"`
  - `discussions`: Array containing the 3 discussion items.
