# Implementation Plan - Multiple Files Support for `notesUrl` with Modal Popup

Support multiple note files in `notesUrl` for `course.json` and `technical.json`, similar to `relatedLectureId` in `resource.json`. When `notesUrl` contains multiple items, clicking the "Lecture Notes" button will open an interactive popup modal displaying the list of available notes.
