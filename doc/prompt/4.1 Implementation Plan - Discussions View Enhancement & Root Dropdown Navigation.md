# Implementation Plan - Discussions View Enhancement & Root Dropdown Navigation

This plan outlines the structural refactoring of the Discussions view to introduce two root-level drop-down menus ("Technical Discussions" and "Course Discussions"), create `technical.json` and `course.json`, add a YouTube technical discussion entry, and make every card and root dropdown copiable via deep-link URLs.

## User Review Required

> [!NOTE]
> The root drop-down menus will allow users to collapse/expand "Technical Discussions" and "Course Discussions" independently, while deep links (e.g., `#discussions?section=technical` or `#discussions?discussion=tech-disc-1`) will automatically expand parent accordions and scroll/highlight target elements.
